# 2026-11-24 会话分组、标读与资料验收

起点为 `7c0a881de51bb895c16b7dacfa196b4a3894d503`。在 Linux 上用 GCC 16.2.0 和 Qt 6.5.3 构建了 Debug 和 Release 的 `chat_server`、`chat_client`、`chat_qt`。所有账号、SQLite、Qt 应用目录及附件回归使用的 Silo 数据均为隔离数据。

| 入口 | 实测结果 |
|---|---|
| `linux.sh` | Release 全流程退出码 0，输出 35 条 PASS。包含真实 WebSocket、SDK、Qt、归档读取、Outbox 对账、上传恢复及 Silo 引用回收。 |
| `conversation_folders.py` | 两个设备读取相同分组顺序，另一账号无法操作。隐藏后归组保留，失权后无法移动，重入回到未分组。重启后显示超过一页的会话，最新活动在组内调整顺序。 |
| `folder_interaction.py` | 带着草稿与回复目标时，旧实现可能在按下鼠标后因列表刷新而丢失拖动。临时 Qt 事件跟踪显示，鼠标仍位于「研发」行时当前索引已回到「b」。改为使用按下时的会话 ID 后，独立 Xvfb 进程连续三轮完成拖放、右键移动、三层标读和重启恢复折叠状态。 |
| `bulk_read.py` | 除 RPC 响应外，核对了 SQLite 行、本人其他设备的视图事件及另一成员收到的已读位置。覆盖隐藏、免打扰、清空、重入、超出第一页的会话，以及和标读并发及在其后提交的新消息。 |
| `user_profiles.py` | 在真实资料窗口编辑昵称和签名。重复昵称和 Unicode 边界通过。修改备注时已有消息、回复、转发同步更新。群内选择昵称后，消息仍保存原用户名和正确的提及用户 ID。删除好友后共同群仍可授权签名，退出最后的共同群后服务端与已打开窗口都收回签名。 |
| `group_profiles.py` | Qt 文件选择器上传群头像。用户和群的数字 ID 同为 2，红色用户头像和蓝色群头像分别取回；清除群头像保留用户图像。验证成员界面、管理员权限变化、上传中降级、客户端重启、成员过滤和公告独立性。 |
| `bookmarks.py --probe`、`message_selection.py` | 额外的收藏、多选和普通转发回归均以退出码 0 结束。 |

复跑入口及依赖见[隔离验收说明](../README.md)。本次使用 Xvfb 或 Qt offscreen。Wayland、Portal 和实际登录桌面未执行。
