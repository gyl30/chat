# 2026-11-21 Linux Release 同连接对照

相同 Ubuntu 22.04.5 / GCC 16.0.1 / SQLite 3.51.3 候选库和计时程序，热库 120,000 条合成消息。每组预热 2 次，记录 100 次；每种模式使用新建的库，写入者始终与搜索者是同一账号。同连接与跨连接的区别只是发送使用原连接还是同账号的第二连接。两组无命中的发送均在搜索响应前提交（100/100）。

|---|---:|---:|
| 无搜索 | 6.945 / 10.148 | 6.737 / 10.353 |
| 并发无命中搜索 | 164.844 / 165.755 | 16.108 / 17.245 |

[同连接原始 JSON](20261121-release-same.json) · [跨连接原始 JSON](20261121-release-cross.json)。
仅根据同一个 JSON 中的非预热样本取最近秩 P95/P99。同连接等待发生在连接的顺序分发上，不能仅拿数据库排队值衡量；没有修改 RPC 的执行模型。数据是本机合成负载，不代表生产 SLO。

绝对时间是单次进程的单调时钟纳秒，其他延迟为毫秒，不能跨运行直接比较绝对值。无搜索时不记录搜索字段。提交时间为客户端开始发送帧，响应为客户端单一接收者读到对应 RPC ID；发送执行时间只包括服务端数据库工作，搜索执行包括 SQL、读取及结果装配。WAL 与 checkpoint 在每组结束后采集，不是运行中峰值。
